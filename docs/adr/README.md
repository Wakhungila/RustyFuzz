# Architecture Decision Records

Status: CURRENT process.

ADR files record architectural decisions before production code moves happen.
The `000N-*` ADR series is the canonical re-engineering series. Older ADR files
without zero-padded names are retained as historical context.

Required sections:

- Status
- Context
- Decision
- Alternatives Considered
- Consequences
- Migration Notes

Status values:

- `Accepted`: approved target direction.
- `Proposed`: expected direction with unresolved questions.
- `Superseded`: retained for historical context only.
