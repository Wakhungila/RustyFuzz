# RustyFuzz Stage 0 Codebase Inventory

Date: 2026-08-26
Commit inspected: `9caf67d528ce3e824c29dae6050726150d2c6a2f`

This inventory was produced before any production-code restructuring. Source files under `src/**`, tests, benchmarks, workflows, existing docs, and configuration examples were inspected. Generated audit logs, saved campaign archives, and bulk runtime outputs were inventoried by path/size only.

## Executive Map

RustyFuzz is currently a single Cargo package named `rusty-fuzz`. The supported default build is EVM-first with LibAFL and REVM. There is real implementation in the current EVM executor, fork database, mutator, feedback, snapshot corpus, benchmark validation, replay/minimization/promotion, and Satori static-analysis pipeline. The architecture is still tightly coupled: core domain types depend directly on REVM and EVM modules; the CLI and `engine::fuzz_engine` own too much orchestration; artifact paths are reconstructed in several places; finding lifecycle terminology is inconsistent across code and docs.

Current dependency reality:

```text
src/main.rs
  -> config + engine + evm + common + satori

engine::fuzz_engine
  -> LibAFL + REVM + evm executor/fork/corpus/feedback + oracles + promotion + benchmark/seed/ABI helpers

common::types
  -> REVM + evm::fork_db + evm::fuzz::EvmInput

evm::*
  -> REVM + Alloy + LibAFL where needed

common::oracle::* and src/oracles/*
  -> common types + REVM + engine economic deltas in places

satori::*
  -> optional AI/static-analysis/reporting pipeline; OpenAI-compatible call is hardcoded in `reasoning::o3_client`
```

## Inventory Legend

- Deps are recorded as `L` = LibAFL, `R` = REVM/Alloy EVM stack, `O` = oracle subsystem, `AI` = Satori/LLM.
- Side effects include filesystem, network, process spawning, environment reads, stdout/stderr, global/thread-local mutable state, and shared locks.
- Status/action values use the requested categories: production, useful but coupled, experimental, stub, duplicated, obsolete; preserve, move, split, merge, rewrite, quarantine, delete.
